# AtaPotify

**AtaPotify** is an Android app built with Kotlin and Jetpack Compose for splitting a shared **Spotify Family** subscription in **LKR** and tracking monthly listening stats with friends.

## Features
- **Monthly Payment Board**: Track each member's monthly LKR share (`Paid`, `Verifying`, or `Pending`), upload transfer slips, and receive cycle reminder notifications.
- **Spotify Listening Leaderboard**: Connect Spotify to sync monthly listening minutes, top artists, and top tracks.
- **Approval Mode & Admin Tools**: Sign in with Google to request access, approve members from the Admin tab, browse billing history, and send WhatsApp reminders.
