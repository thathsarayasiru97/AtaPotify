# AtaPotify

**AtaPotify** is an Android app built with Kotlin and Jetpack Compose for splitting a shared **Spotify Family** subscription in **LKR** and tracking monthly listening stats with friends.

## Features
- **Monthly Payment Board**: Track each member's monthly LKR share (`Paid`, `Verifying`, or `Pending`) and upload transfer slips.
- **Spotify Value Leaderboard**: Connect Spotify to sync monthly listening minutes, top artists/tracks, and `LKR/hr` value.
- **Billing History & Admin Tools**: Browse past billing cycles, manage whitelisted family members, and send WhatsApp reminders.
